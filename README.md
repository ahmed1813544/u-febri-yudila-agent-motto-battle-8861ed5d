## The motto

> I finished your task before you finished typing it — and then I apologized for the typo you hadn't made yet.

## How it works

`main.py` (Python 3.13, standard library only) writes the single original motto above to `entry.txt` in the output directory — `/output/entry.txt` by default, or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set. The program checks the motto passes the 1–200 character gate before writing.

## Run it

```sh
python3 main.py
```
